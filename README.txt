Worship Service Assistant.

(1) What is Contained in the Worship Service Assistant Archive?

The 'Worhsip Service Assistant' folder contains
this readme file (README.txt),
the Worship Service Assistant PowerPoint add-in (WorshipServiceAssistant.ppa),
the Worship Service Assistant HTML help file (WorshipServiceAssistant.chm),
the Source folder containing the add-in and help file source,
the Samples folder containing sample presentation files.

(2) What is Worship Service Assistant?

Worship Service Assistant is a Microsoft PowerPoint 2000 add-in
that simplifies the use of Microsoft PowerPoint in a worship service.
More details can be found in the Worship Service Assistant HTML help
file (WorshipServiceAssistant.chm).

(3) How do I Use Worship Service Assistant.

Before using Worship Service Assistant, you must read and accept the
copyright and license found in the Worship Service Assistant HTML help
file (WorshipServiceAssistant.chm).

Worship Service Assistant has been tested using Microsoft PowerPoint 2000
running on Microsoft Windows 2000 and Microsoft Windows XP. If you are using
a different version of PowerPoint, then it is likely that Worship
Service Assistant will not work correctly.  If you are using an older
version of Windows, then it is likely that Worship Service Assistant will
not run correctly.  If you are using a newer version of Windows, then it
is likely that Worship Service Assistant will run correctly.

The Worship Service Assistant HTML help file (WorshipServiceAssistant.chm)
should provide all the information you need in order to install and use
the Worship Service Assistant add-in (WorshipServiceAssistant.chm).
