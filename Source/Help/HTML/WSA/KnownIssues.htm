Known Issues

  1. Running slide shows stall under PowerPoint 2002 - When a slide show is run using the Slide Show Run button in the Nagivator window, the slide show may stall (stop running). Unfortunately, PowerPoint thinks that the slide show is still running. As a result, there is no way for Worship Service Assistant to detect that the slide show has stalled. In addition, I have found no method by which Worship Service Assistant can workaround to this problem. However, it appears that manually advancing to the next slide show effect causes the slide show to continue running. You can manually advance to the next slide show effect by clicking the Slide Show Next Effect button in the Navigator window.
