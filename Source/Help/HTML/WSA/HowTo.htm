How To ...

You may need to perform the following tasks before the worship service. Once you have completed these tasks you will not need to perform them again.

  • Set Up the Equipment.
  • Create a Song File.
  • Categorize Songs.
  • Sort Songs.
  • Create a Song Index.

You may need to perform the following tasks during the worship service.

  • Display a Slide (such as a song).
  • Display a Manual Presentation (such as a sermon).
  • Display a Timed Presentation (such as announcements).
  • Display a Banner (such as a nursery call number).
