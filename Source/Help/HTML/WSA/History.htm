History

Version 1.01.0006 Changes:

Release date: February 9, 2002.

  1. Worked around problem where PowerPoint XP would prompt the user to save some presentations already marked as saved; in particular the presentation used to create the banner.

Version 1.01.0005 Changes:

Release date: February 8, 2002.

  1. Changed the Navigator so that it automatically hides any floating and pop-up command bars because they may get in the way of the form.
  2. Changed the Navigator so that the Navigator Presentation page and Banner page default buttons are hightlighted.
  3. Changed the Navigator Slide Selection Title matching so that it matches 'm and m.
  4. Worked around a bug when running under Windows XP and PowerPoint XP that would cause the banner to fail to display.

Version 1.01.0004 Changes:

Release date: February 8, 2002.

  1. Added support for Microsoft PowerPoint XP.
  2. Fixed a bug that caused the Presentation page Slide Show Show/Hide button to not update.

Version 1.01.0003 Changes:

Release date: October 15, 2001.

  1. Changed Navigator that the presentation window resizing would zoom to fit the slide.
  2. Changed Navigator so that the slide miniature would not automatically appear.
  3. Changed the Navigator form resizing so that it does not resize differently for the Presentation and Banner pages.
  4. Fixed a bug in the Navigator form resizing.
  5. Fixed errors in Navigator control tip text.
  6. Fixed version number. Version 1.01.0002 claimed that it was version 1.01.0001.
  7. Hid Navigator form page tabs.

Version 1.01.0002 Changes:

Release date: October 08, 2001.

  1. Added banner color support.

Version 1.01.0001 Changes:

Release date: July 03, 2001.

  1. Changed the license to the X11 license from the GNU General Public License. Unlike the GNU General Public License, the X11 license is not a copyleft license. Therefore, developers can include code from Worship Service Assistant within their code without requiring that their code be free software.

Version 1.01.0000 Changes:

Release date: May 21, 2001.

  1. Added banner support.
  2. Removed 'Load' and 'Hide' controls from the menu.
  3. Changed the Navigator so that the slide title would match the title displayed in the list box.
  4. Added 'Children' and 'Liturgy' categories.

Version 1.00.0003 Changes:

Release date: March 03, 2001.

  1. Added Samples folder.

Version 1.00.0002 Changes:

Release date: February 24, 2001.

  1. Fixed a bug in the command bar where it may not be up-to-date. Now, when a command bar control is activated (clicked), the command bar is updated. If, as a result, the activated control is disabled, then the control is not executed.
  2. Fixed a bug in the Navigator where the form would load even if there was no active window.

Version 1.00.0001 Changes:

Release date: February 04, 2001.

  1. Removed context sensitive help, because VBA 6.0 does not support HTML help context sensitive help.
  2. Changed the Navigator slide title filter to match commonly interchanged words.
  3. Changed the "Help" menu's help topic items to use Windows API calls.
  4. Changed the "Help" menu's "Visit the Homepage" and "Email the Author" items to use Windows API calls.
  5. Changed the "Song Edit" menu's "Sort" menu item so that it would collapse slides in the outline pane.
  6. Changed the "Song Edit" menu's "Set Category" menu, the "Debug" menu's "SSW Display" and the "Debug" menu's "SSW Size" to be more flexible. Currently, only the "SSW Display" menu uses the flexibility. Now, the "SSW Display" menu only contains monitors that exists. The other menus will use the flexibility if I add configuration options to Worship Service Assistant.
  7. Fixed a bug where part of the presentation window would appear on the slide show display under certain conditions while the Navigator is launching.
  8. Fixed some errors in the help file.

Version 1.00.0000 Changes:

Release date: January 21, 2001.

  1. Initial Revision.
