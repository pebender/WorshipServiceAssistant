History

Version 1.04.0000 Changes:

Release date: August 17, 2002.

  1. Changed the slide body matching performed by the Navigator Slide Selection frame so that the matching starts at word boundaries.
  2. Changed the slide body matching performed by the Navigator Slide Selection frame so that the matching is the same "forgiving" matching used for slide title matching.
  3. Sped up the matching when the Navigator Slide Selection Mode is set to filter on the body.
  4. Hid the banner presentation document window.
  5. Fixed a bug that would cause PowerPoint to crash when a Worship Service Assistant toolbar menu was clicked and Worship Service Assistant had crashed.
  6. Restructured the code for the Navigator. In the past, the Navigator form, with the help of some Navigator support modules, implemented both the Navigator's front end and the Navigator's back end. Now, the Navigator form implements only the Navigator's front end. The Navigator's back end is implemented by several class modules. The Navigator support modules no longer exist. This restructuring made it easier to add the faster filter matching and makes the code easier to maintain.

Version 1.03.0002 Changes:

Release date: July 29, 2002.

  1. Fixed a bug that caused the Navigator Slide Selection list to display the incorrect slide titles.
  2. Changed the source code so that it follows Microsoft's Visual Basic coding conventions.
  3. Changed the style of the frame borders in the Navigator.
  4. Made the Navigator Slide Selection frame border color dependent on the Navigator Slide Selection Mode.

Version 1.03.0001 Changes:

Release date: July 23, 2002.

  1. Fixed a bug that caused Navigator Slide Selection speed to be much slower in version 1.03.0000 than in version 1.03.0000 when the filter mode is matching slide number and slide body.
  2. Fixed a bug that caused Worship Service Assistant to crash when no slide was selected in the slide window of the slide thumbnail pane in normal view.
  3. Added code to work around the PowerPoint 2000 VBA API bug described in Microsoft knowledge base article Q285436. This bug caused Worship Service Assistant to crash when at least one of the open document window's was in slide master view and Navigator was started.
  4. Change Navigator so that it changes the window view of open presentations to the slide view rather than the normal view.

Version 1.03.0000 Changes:

Release date: July 18, 2002.

  3. Added the "Mode" button and "Mode Name" display to the Navigator Slide Selection frame in order to allow the operator to select the filter mode.
  4. Renamed Navigator Slide Selection Title to Navigator Slide Selection Text.

Version 1.02.0000 Changes:

Release date: February 17, 2002.

  1. Removed official support for Microsoft Windows 2000 (aka Windows 5.0). Since my church has switched from Windows 2000 to Windows XP, I no longer test Worship Service Assistant under Windows 2000. However, I know of no reason that it will not run under Windows 2000.
  2. Removed official support for Microsoft PowerPoint 2000 (aka PowerPoint 9.0). Since my church has switched from Office 2000 to Office XP, I no longer test Worship Service Assistant under PowerPoint 2000. However, I know of no reason that it will not run under PowerPoint 2000.
  3. Changed the Navigator so that it automatically configures PowerPoint options to values most appropiate for running the Navigator.
  4. Fixed a bug that caused the "Debug" "SSW Display" "Default" menu item to set to default the slide show's size rather than the slide show's display.
