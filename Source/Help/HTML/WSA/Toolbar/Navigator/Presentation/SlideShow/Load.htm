Load Botton

Clicking the 'Load' button in the 'Slide Show' frame loads the currently selected slide into the slide show and the slide show will be paused. If the selected presentation does not have a slide show, then a slide show will be created and all other slide shows exists will be exited. The ENTER key has the same effect as the 'Load' button.

The 'Load' button is designed to be used during the worship service. It allows the operator to display the currently selected slide. Simply select a slide and click the 'Load' button or use the ENTER key.
