Number Display

The 'Number' display in the 'Slide Selection' frame shows the slide number filter being applied to the 'List' display.

The slide number filter is designed to be used during the worship service. Simply type numbers and they will appear in the 'Number' display. Only the slide with the corresponding slide number will appear in the 'List' display. The BACKSPACE key can be used to clear the slide number filter one number at a time. The DELETE key can be used to clear the entire slide number filter.
