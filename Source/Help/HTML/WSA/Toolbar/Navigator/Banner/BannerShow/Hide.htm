Hide/Show Button

Clicking the 'Hide/Show' button in the 'Banner Show' frame toggles the active presentation's slide show between black and paused. The CONTROL+B and CONTROL+S key combinations have the same effect as the 'Hide/Show' button.

The 'Hide/Show' button is designed to be used during the worship service. It allows the operator to toggle the banner between hidden and shown. Simply click the 'Hide/Show' button or use the CONTROL+H or CONTROL+S key combinations.
