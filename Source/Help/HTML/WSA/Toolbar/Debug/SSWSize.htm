SSW Size Menu

The 'SSW Size' menu in the 'Debug' menu on the Worship Service Assistant toolbar sets the slide show window size.

By default, Worship Service Assistant uses a full size slide show window. Being able to set the slide show window display is useful when testing Worship Service Assistant on a computer with one display. Worship Service Assistant will revert to the default when the 'Debug' menu is hidden.
