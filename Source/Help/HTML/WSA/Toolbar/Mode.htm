Mode Menu

The 'Mode' menu on the Worship Service Assistant toolbar provides functions for setting the Worship Service Assistant mode.

The 'Mode' menu contains three menu items:

  • the 'Operator' menu item - for putting Worship Service Assistant into Operator mode,
  • the 'Editor' menu item - for putting Worship Service Assistant into Editor mode,
  • the 'Developer' menu item - putting Worship Service Assistant into Developer mode,

The 'Mode' menu is available in all modes.
