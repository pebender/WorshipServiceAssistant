Song Edit Menu

The 'Song Edit' menu on the Worship Service Assistant toolbar provides functions used to prepare song files.

The 'Song Edit' menu contains three menu items:

  • the 'Set Category' menu - for setting the category of the selected song slides,
  • the 'Set Template' menu item - for changing the song file template,
  • the 'Sort' menu item - for sorting the selected song slides into aphabetical order, and
  • the 'Create Index' menu item - for creating an index of the songs in the song file.

The 'Song Edit' menu is available in 'Editor' mode and in 'Developer' mode.
