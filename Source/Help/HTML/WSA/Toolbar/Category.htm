Category Display

The 'Category' display on the Worship Service Assistant command bar displays the category of the selected slide(s). The 'Category' display will be blank if any of the following is true:

  • There are no selected slides.
  • The selected slides are not in a category.
  • The selected slides are not all in the same category.

The 'Category' display is available in 'Editor' mode and in 'Developer' mode.
