Navigator

The Navigator button on the Worship Service Assistant toolbar launches the Navigator.

The Navigator is designed to be used during the worship service. It allows the operator to

  • select and display slides from a large presentation (such as a song file),
  • display a manual presentation (such as a sermon),
  • display a timed presentation (such as announcements), and
  • display a banner (such as nursery call numbers).

The Navigator contains one general frame:

  • the 'General' frame - for controlling the Navigator.

In addition, the Navigator contains two functional pages:

  • the 'Presentation' page - for controlling the presentation, and
  • the 'Banner' page - for controlling the banner.

One page is visible at a time. You can see the name of the current page on the Navigator title bar. You can move between the pages by clicking the 'Next Page' button in the 'General' frame or using the TAB key.

The Navigator is available in 'Operator' mode, in 'Editor' mode and in 'Developer' mode.
