Load Botton

The 'Load' button on the Worship Service Assistant command bar loads the currently selected slide into the slide show.

The 'Load' button is designed to be used during the worship service. It allows the operator to display the currently selected slide. Simply select a slide and click the 'Load' button. If the selected presentation does not have a slide show, then a slide show will be created. If another presentation slide shows exists, then it will be exited.

It should be noted that this button's behavior is slightly different from the Navigator's 'Load' button. After clicking this button, the presentation's slide show is the active window. After clicking the Navigator's 'Load' button, the presentation is the active window.
