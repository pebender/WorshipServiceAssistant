Mode Button

The 'Mode' button in the 'Slide Selection' frame changes the slide filter mode. There are two slide selection filter modes: "Filter matching Number and Title" and "Filter matching Number and Title and Body". The CONTROL+M key combination has the same effect as the 'Mode' button.

The 'Mode' button is designed to be used during the worship service. It allows the operator to change the slide selection filter mode. Simply click the 'Mode' botton or use the CONTROL+M key combination.
