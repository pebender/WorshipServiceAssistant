Text Display

The 'Text' display in the 'Slide Selection' frame shows the slide text filter being applied to the 'List' display.

The slide text filter is designed to be used during the worship service. Simply type alphanumeric characters and they will appear in the 'Text' display. If the 'Mode' is set to filter on slide title, then only the slides with titles starting with the text in the 'Text' display will appear in the 'List' display. If the 'Mode' is set to filter on slide title and body, then only the slides with titles starting with the text in the 'Text' display and slides with bodies containing the text in the 'Text' display will appear in the 'List' display. The BACKSPACE key can be used to clear the slide title filter one character at a time. The DELETE key can be used to clear the entire slide title filter.
