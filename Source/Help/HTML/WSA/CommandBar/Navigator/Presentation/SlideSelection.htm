Slide Selection Frame

The 'Slide Selection' frame on the 'Presentation' page of the Navigator allows you to quickly find and select a slide by filtering out unwanted slides. How slides are filtered depends on the 'Slide Selection' 'Mode'. There are two slide filter modes: "Filter matching Number and Title" and "Filter matching Number and Title and Body". The color of the 'Slide Selection' frame border depends on the 'Slide Selection' 'Mode'.

If the filter criteria is numeric, then the Navigator assumes that the filter is a slide number. When the Navigator is assuming that the filter is a slide number, the Navigator places the filter text in the 'Slide Selection' 'Number' display. When filtering on number, only the slide with the corresponding slide number will appear in the 'List' display.

If the filter criteria is not numeric, then the Navigator assumes that the filter is slide text. When the Navigator is assuming that the filter is slide text, then Navigator places the filter text in the 'Slide Selection' 'Text' display. When filtering on text, the Navigator matches the text starting at word boundaries. In addition, the Navigator window attempts to be somewhat forgiving. Capitalization, punctuation and white space are not considered when filtering. For example, the filter "lord i lift" will match the text "Lord, I lift". When the filter mode is "Filter matching Number and Title", only slides whose title begins with the filter text will appear in the 'Slide Selection' 'List' display. When the filter mode is "Filter matching Number and Title and Body", only slides whose title or body contains the filter text will appear in the 'Slide Selection' 'List' display.
