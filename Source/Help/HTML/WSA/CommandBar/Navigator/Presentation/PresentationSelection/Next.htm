Next Button

Clicking the 'Next' button in the Presentation Selection frame makes the next open presentation the selected presentation. If there are no other open presentations, then the 'Next' button has no effect. The RIGHT_ARROW key has the same effect as the 'Next' button.

The 'Next' button is designed to be used during the worship service. It allows the operator to select the next open presentation without exiting the Navigator. Simply click the 'Next' button or use the RIGHT_ARROW key.
