Prev Button

Clicking the 'Prev' button in the Presentation Selection frame makes the previous open presentation the selected presentation. If there are no other open presentations, then the 'Prev' button has no effect. The LEFT_ARROW key has the same effect as the 'Prev' button.

The 'Prev' button is designed to be used during the worship service. It allows the operator to select the previous presentation without exiting the Navigator. Simply click the 'Prev' button or use the LEFT_ARROW key.
