Prev Effect Button

Clicking the 'Prev Effect' button in the 'Slide Show' frame causes the active presentation's slide show to go to the previous effect (either an animation or a slide). If the active presentation does not have a slide show, then the 'Prev Effect' button is disabled. The CONTROL+UP_ARROW key combination has the same effect as the 'Prev Effect' button.

The 'Prev Effect' button is designed to be used during the worship service. It allows the operator to go backward in the slide show without exiting the Navigator. Simply click the 'Prev Effect' button or use the CONTROL+UP_ARROW key combination.
