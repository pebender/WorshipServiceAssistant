Pause Button

Clicking the 'Pause' in the 'Slide Show' frame button pauses active presentation's slide show. If the active presentation does not have a slide show, then the 'Pause' button is disabled. The CONTROL+P key combination has the same effect as the 'Pause' button.

The 'Pause' button is designed to be used during the worship service. It allows the operator to pause a running slide show. Simply click the 'Pause' button or use the CONTROL+P key combination.
