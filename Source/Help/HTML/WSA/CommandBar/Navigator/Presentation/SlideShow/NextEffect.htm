Next Button

Clicking the 'Next Effect' button in the 'Slide Show' frame causes the active presentation's slide show to go to the next effect (either an animation or a slide). If the active presentation does not have a slide show, then the 'Next Effect' button is disabled. Using the CONTROL+DOWN_ARROW key combination has the same effect as the 'Next Effect' button.

The 'Next Effect' button is designed to be used during the worship service. It allows the operator to go forward in the slide show without exiting the Navigator. Simply click the 'Next Effect' button or use the CONTROL+DOWN_ARROW key combination.
