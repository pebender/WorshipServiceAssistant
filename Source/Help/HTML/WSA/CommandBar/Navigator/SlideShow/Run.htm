Run Button

Clicking the 'Run' button in the Slide Show frame in the Navigator frame starts the active presentation's slide show running. If the active presentation does not have a slide show, then the 'Run' button is disabled. The CONTROL+R key combination has the same effect as the 'Run' button.

The 'Run' button is designed to be used during the worship service. It allows the operator start a slide show running. Simply click the 'Run' button or use the CONTROL+R key combination.
