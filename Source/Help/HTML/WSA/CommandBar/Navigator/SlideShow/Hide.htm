Hide/Show Button

Clicking the 'Hide/Show' button in the Slide Show frame in the Navigator frame toggles the active presentation's slide show between black and paused. If the active presentation does not have a slide show, then the 'Hide/Show' button is disabled. The CONTROL+B and CONTROL+S key combinations have the same effect as the 'Hide/Show' button.

The 'Hide/Show' button is designed to be used during the worship service. It allows the operator to toggle the slide show between hidden and shown. Simply click the 'Hide/Show' button or use the CONTROL+H or CONTROL+S key combinations.

It should be noted that this button's behavior is slightly different from the command bar's 'Hide' button. After clicking this button, the presentation's window is the active window. After clicking the command bar's 'Hide' button, the presentation's slide show is the active window.
