Load Button

Clicking the 'Load' button in the 'Banner Show' frame loads the text in the 'Text' display into the banner display above the presentation. The ENTER key has the same effect as the 'Load' button.

The 'Load' button is designed to be used during the worship service. It allows the operator to display banner text above the presentation. Simply enter the banner text and click the 'Load' button or use the ENTER key.
