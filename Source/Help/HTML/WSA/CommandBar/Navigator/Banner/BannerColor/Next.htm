Next Button

Clicking the 'Next' button in the Banner Color frame makes the next banner color the selected banner color. The RIGHT_ARROW key has the same effect as the 'Next' button.

The 'Next' button is designed to be used during the worship service. It allows the operator to select the next banner color. Simply click the 'Next' button or use the RIGHT_ARROW key.
