Prev Button

Clicking the 'Prev' button in the Banner Color frame makes the previous banner color the selected banner color. The LEFT_ARROW key has the same effect as the 'Prev' button.

The 'Prev' button is designed to be used during the worship service. It allows the operator to select the previous banner color. Simply click the 'Prev' button or use the LEFT_ARROW key.
