List Display

The 'List' display in the Slide Selection frame in the Navigator frame allows shows all the slides in the active presentation that match the slide number filter and slide title filter. You can select any slide in the 'List' display.

The 'List' display is designed to be used during the worship service. Use the mouse or the UP_ARROW and DOWN_ARROW keys to select a specific slide in the 'List' diplay.
