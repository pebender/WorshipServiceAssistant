Song Edit Menu

The 'Song Edit' menu on the Worship Service Assistant command bar provides functions used to prepare song files.

The 'Song Edit' menu contains four menu items:

  • the 'Set Category' menu - for setting the category of the selected song slides,
  • the 'Sort' menu item - for sorting the selected song slides into aphabetical order,
  • the 'Create Index' menu item 'Create Index' menu - for creating an index of the songs in the song file,
