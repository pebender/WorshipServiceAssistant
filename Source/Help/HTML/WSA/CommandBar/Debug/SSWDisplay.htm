SSW Display Menu

The 'SSW Display' menu in the 'Debug' menu on the Worship Service Assistant command bar sets the slide show window display.

By default, Worship Service Assistant uses the last display for the slide show window. Being able to set the slide show window display to a different display when testing Worship Service Assistant where the slide show cannot be displayed on the last display. Worship Service Assistant will revert to the default when the 'Debug' menu is hidden.

By default, the 'Debug' menu is hidden. The 'Debug' menu item in the 'Help' menu can be used to show or hide the 'Debug' menu.
