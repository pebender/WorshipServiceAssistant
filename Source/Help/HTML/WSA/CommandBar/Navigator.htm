Navigator

The Navigator button on the Worship Service Assistant command bar launches the Navigator.

The Navigator is designed to be used during the worship service. It allows the operator to

  • select and display slides from a large presentation (such as a song file).
  • display a manual presentation (such as a sermon).
  • display a timed presentation (such as announcements).

The Navigator functions are divided into four groups (called frames): the

  • the 'General' frame,
  • the 'Presentation Selection' frame - for selecting the desired presentation,
  • the 'Slide Selection' frame - for selecting the desired slide, and
  • the 'Slide Show' frame - for controlling the slide show.

Since it is often faster to use keyboard sortcuts rather than the mouse, all the Navigator functions have keyboard shortcuts.
