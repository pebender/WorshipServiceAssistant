Debug Menu

The 'Debug' menu on the Worship Service Assistant command bar provides functions for use in debugging the Worship Service Assistant.

The 'Debug' menu not designed to be used during normal operation. By default, the 'Debug' menu is hidden. The 'Debug' menu item in the 'Help' menu can be used to show or hide the 'Debug' menu.

The 'SSW Display' menu allows the user to set the slide show window display. By default, Worship Service Assistant uses the last display for the slide show window. Worship Service Assistant will revert to the default when the 'Debug' menu is hidden.

The 'SSW Size' menu allows the user to set the slide show window size. By default, Worship Service Assistant uses a full size slide show window. Worship Service Assistant will revert to the default when the 'Debug' menu is hidden.
