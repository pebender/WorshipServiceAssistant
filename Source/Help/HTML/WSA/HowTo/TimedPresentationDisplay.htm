How to Display a Timed Presentation

Some presentations, such as announcements, used during the worship service may be timed presentations. These presentations contain timing information that advances the slide show automatically. Worship Service Assistant makes it easy for you to display this type of presentation.

First, before you start the Navigator, make sure that the presentation that you wish to display is opened.

Second, if the Navigator is not already running, then start it by clicking the 'Navigator' button on the Worship Service Assistant command bar.

Third, select the presentation containing the slide you wish to display by pressing the LEFT_ARROW and RIGHT_ARROW keys until the presentation name appears in the 'Title' display in the 'Presentation Selection' frame in the Navigator.

Fourth, load the presentation into the slide show by hitting the ENTER key. The slide show will start paused and will start displaying the slide selected in the Navigator.

Fifth, click the 'Run' button in the 'Slide Show' frame in the Navigator to start the slide show running. The slide show will start over after last slide in the presentation is displayed. If for any reason you wish to pause the slide show, then click the 'Pause' button in the 'Slide Show' frame in the Navigator.
