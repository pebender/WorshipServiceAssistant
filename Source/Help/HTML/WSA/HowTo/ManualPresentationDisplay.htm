How to Display a Manual Presentation

Some presentations, such as sermons, used during the worship service may be manual presentations. These presentations may contain animation effects that require advancing through the slide show, rather than just loading the next slide. Worship Service Assistant makes it easy for you to display this type of presentation.

First, use the 'Operator' menu item in the 'Mode' menu on the Worship Service Assistant toolbar to put Worship Service Assistant into Operator mode.

Second, before you start the Navigator, make sure that the presentation that you wish to display is opened.

Third, if the Navigator is not already running, then start it by clicking the 'Navigator' button on the Worship Service Assistant toolbar.

Fourth, select the Navigator's 'Presentation' page by pressing the TAB key until 'Navigator - Presentation' appears in the Navigator's title bar.

Fifth, select the presentation containing the slide you wish to display by pressing the LEFT_ARROW and RIGHT_ARROW keys until the presentation name appears in the 'Title' display in the 'Presentation Selection' frame in the Navigator.

Sixth, load the presentation into the slide show by hitting the ENTER key. The slide show will start paused and will start displaying the slide selected in the Navigator.

Seventh, you can go backward and forward in the slide show using the CONTROL+UP_ARROW key combination and the CONTROL+DOWN_ARROW key combination respectively You can go to a specific slide by selecting the slide in the Navigator and hitting the ENTER key.
