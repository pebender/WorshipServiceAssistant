How to Create a Song File

A song file is a Microsoft PowerPoint presentation with some restrictions on the slide titles.

Slide Title Restrictions

Each slide should include a slide title. Worship Service Assistant uses the slide title when sorting, indexing and displaying songs. If the slide does not contain a slide title, then the slide will be sorted to the beginning of the presentation when you sort the songs. If the slide does not contain a slide title, then the slide will not appear in the index when you create a song index. If the slide does not contain a slide title, then only a slide number will appear in the Navigator making it more difficult when you display a song.

If the song requires more than one slide, then the slide title should be of the form "title (X of Y). For example, if the song "Amazing Grace" required two slides, then the two slides should have the titles: "Amazing Grace (1 of 2)" and "Amazing Grace (2 of 2)". This slide title format is recognized when creating the slide index. If this slide title format is used, then only the first slide of the song will be included in the index and the (X of Y) will be removed.

Helpful Hints

You may find it useful to make the slide title the first line of the song. If you do this, then the operator will be able to find the song by typing the first line of the song into the Navigator.

You may find it useful to control the format of you song file using a Master. If you do this, you will be able to easily change the look of the song file for different seasons or events. For example, around the Christmas, you might choose to change the background and text colors to something appropiate to the season.

You may find it useful to display the slide title using a small font and to position the slide title at the bottom of the slide. While the slide title is very useful to Worship Service Assistant operator, it is not very useful to the congregation. As a result, making it less visible is usually a good idea.
