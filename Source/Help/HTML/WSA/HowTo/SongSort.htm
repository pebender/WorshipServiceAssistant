How to Sort Songs

You can use Worship Service Assistant to sort songs into alphabetical order.

First, open the song file containing the songs that you want to sort.

Second, select the song slides that you want to sort.

Third, use the 'Sort' menu item in the 'Song Edit' menu on the Worship Service Assistant command bar to sort the selected slides. Worship Service Assistant will notify you when it has completed sorting the selected slides. The time needed to sort the slides depends on several things, including the speed of the computer, the number of selected slides and the order of selected slides.
