How to Set Up the Equipment

There are several things that you need to do in order to make sure that your equipment is set up to run Worship Service Assistant.

Video Configuration

Worship Service Assistant assumes that your computer has at least two independent video outputs. One video output (typically connected to a video monitor) is viewed by the operator. One video output (typically connected to a video projector) is viewed by the congregation. If your computer has only one video output, then you cannot use Worship Service Assistant for presentation during the worship service. However, you can still use Worship Service Assistant for development before the worship service.

Worship Service Assistant assumes that the video output viewed by the congregation is the last video output. If this is not how your equipment is configured, then Worship Service Assistant will not operate correctly.

Operating System Selection

Worship Service Assistant has been tested using the following operating systems:

  • Microsoft Windows 2000 Professional.
  • Microsoft Windows XP.

If your computer is running any other operating system, then Worship Service Assistant may not run correctly. However, it should run correctly under any newer Microsoft Windows operating systems (e.g. Microsoft Windows 98 or Microsoft Windows Me). If your operating system is not one the tested operating systems, Worship Service Assistant will warn you and give you the option to run Worship Service Assistant anyway.

Microsoft PowerPoint Version Selection

Worship Service Assistant requires Microsoft PowerPoint. Worship Service Assistant has been tested using the following Microsoft PowerPoint versions:

  • Microsoft PowerPoint 2000.
  • Microsoft PowerPoint XP.

If you computer is running any other Microsoft PowerPoint version, then Worship Service Assistant may not run correctly. If your Microsoft PowerPoint version is not one of the tested versions, Worship Service Assistant will warn you and give you the option to run Worship Service Assistant anyway.

Microsoft Internet Explorer Version Selection

Worship Service Assistant requires Microsoft Internet Explorer. Worship Service Assistant has been tested using the following Microsoft Internet Explorer versions:

  • Microsoft Internet Explorer 5.5 SP2.
  • Microsoft Internet Explorer 6.0.

If your computer is running any other version of Microsoft Internet Explorer, then Worship Service Assistant may not work correctly. However, it should work correctly with Microsoft Internet Explorer 4.0 or greater. The latest version of Microsoft Internet Explorer can be downloaded from Microsoft.

Worship Service Assistant Installation

Worship Service Assistant consists of two files: the Worship Service Assistant Microsoft PowerPoint add-in (WorshipServiceAssistant.ppa) and the Worship Service Assistant help file (WorshipServiceAssistant.chm). In order to install Worship Service Assistant, you need to copy both files into the same folder on your computer. If the help file is not in the same location as the add-in, the add-in will not be able to find the help file.

After copying the files, you need to install the add-in. You can do this by following the steps below.

  1. Start Microsoft PowerPoint.
  2. Select the 'Tools' menu from Microsoft PowerPoint.
  3. Select the 'Add-Ins...' option from the 'Tools' menu.
  4. Select the 'Add New' option from the 'Add-Ins' window.
  5. Locate, select and open the Worship Service Assistant add-in (WorshipServiceAssistant.ppa).
  6. If prompted, select 'Enable Macros'.
  7. Click the 'Close' button.

After following the steps, you should see a new command bar appear in Microsoft PowerPoint. This command bar is the Worship Service Assistant command bar. If you do not see the Worship Service Assistant command bar then Worship Service Assistant may have failed to load. Worship Service Assistant will fail to load if PowerPoint's macro security settings are set to 'High'. If this is the case, then you must lower PowerPoint's macro security settings to 'Medium' in order to run Worship Service Assistant.

Microsft PowerPoint Configuration

By default, Microsoft PowerPoint shows the popup menu button in the slide show. For the sake of appearance, we suggest that you disable it. You can do this by following the steps below.

  1. Start Microsoft PowerPoint.
  2. Select the 'Tools' menu from Microsoft PowerPoint 2000.
  3. Select the 'Options...' option from the 'Tools' menu.
  4. Select the 'View' tab from the 'Options' window.
  5. Locate the 'Slide show' frame in the 'View' tab.
  6. Uncheck the 'Show Popup menu button' in the 'Slide show' frame.
  7. Click the 'Ok' button.
