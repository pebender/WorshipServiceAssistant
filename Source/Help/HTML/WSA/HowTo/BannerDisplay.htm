How to Display a Banner

Sometimes during the worship service it is necessary to display banner text, such as a nursery call number, for the entire congregation to see.

First, if the Navigator is not already running, then start it by clicking the 'Navigator' button on the Worship Service Assistant command bar.

Second, select the Navigator's 'Banner' page by pressing the TAB key until 'Navigator - Banner' appears in the Navigator's title bar.

Third, if the banner is not enabled, then enable it using the CONTROL+E key combination. When the banner is enabled, the 'Banner Disable/Enable' button in the 'Banner Configuration' frame will be labeled 'Banner Disable'. In addition, the 'Banner Show' frame, In addition, the 'Banner Show' frame the 'Banner Color' frame will be enabled.

Fourth, select the color of the banner by pressing the LEFT_ARROW and RIGHT_ARROW keys until the presentation name appears in the 'Name' display in the 'Banner Color' frame.

Fifth, type the text that of the banner. The text will appear in the 'Text' display in the 'Banner Selection' frame.

Sixth, load the text into the banner by hitting the ENTER key.
