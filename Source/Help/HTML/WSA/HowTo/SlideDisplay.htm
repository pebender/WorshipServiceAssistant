How to Display a Slide

Some presentations, such as song files, used during the worship service require jumping between slides. Worship Service Assistant makes it easy for you to use to find and display specific slides from a large presentation.

First, before you start the Navigator, make sure that the presentation containing the slide that you wish to display is opened.

Second, if the Navigator is not already running, then start it by clicking the 'Navigator' button on the Worship Service Assistant command bar.

Third, select the Navigator's 'Presentation' page by pressing the TAB key until 'Navigator - Presentation' appears in the Navigator's title bar.

Fourth, select the presentation containing the slide you wish to display by pressing the LEFT_ARROW and RIGHT_ARROW keys until the presentation name appears in the 'Title' display in the 'Presentation Selection' frame in the Navigator.

Fifth, select a slide by typing the slide number or slide title. The typed slide filter criteria will appear in either the 'Number' display or the 'Title' display in the 'Slide Selection' frame in the Navigator, depending on whether a number or non-number is typed. Slides matching the slide filter criteria will appear in the 'List' display in the 'Slide Selection' frame in the Navigator. If multiple slides match the slide filter criteria, then select the desired slide by using the mouse or pressing the UP_ARROW and DOWN_ARROW keys.

Sixth, display the selected slide by hitting the ENTER key.
