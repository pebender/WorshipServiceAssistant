How to Display a Slide

Some presentations, such as song files, used during the worship service require jumping between slides. Worship Service Assistant makes it easy for you to use to find and display specific slides from a large presentation.

First, use the 'Operator' menu item in the 'Mode' menu on the Worship Service Assistant toolbar to put Worship Service Assistant into Operator mode.

Second, before you start the Navigator, make sure that the presentation containing the slide that you wish to display is opened.

Third, if the Navigator is not already running, then start it by clicking the 'Navigator' button on the Worship Service Assistant toolbar.

Fourth, select the Navigator's 'Presentation' page by pressing the TAB key until 'Navigator - Presentation' appears in the Navigator's title bar.

Fifth, select the presentation containing the slide you wish to display by pressing the LEFT_ARROW and RIGHT_ARROW keys until the presentation name appears in the 'Title' display in the 'Presentation Selection' frame in the Navigator.

Sixth, select the desired slide selection filter mode by pressing the CONTROL+M until the desired slide selection filter mode appears in the 'Slide Selection' frame in the Navigator.

Seventh, select a slide by typing the slide filter criteria. The typed slide filter criteria will appear in either the 'Number' display or the 'Text' display in the 'Slide Selection' frame in the Navigator, depending on whether a numeric or non-numeric slide filter criteria is typed. Slides matching the slide filter criteria will appear in the 'List' display in the 'Slide Selection' frame in the Navigator. If multiple slides match the slide filter criteria, then select the desired slide by using the mouse or pressing the UP_ARROW and DOWN_ARROW keys.

Eigth, display the selected slide by hitting the ENTER key.
