How to Categorize Songs

You can use Worship Service Assistant to categorize songs into one of the following categories: '', 'Worship', 'Choir', 'Hymn' and 'Carol'. If you categorize your songs, then the songs will be grouped by category in the song index. This can be useful if your music director wishes to use the song index to find a particular type of song for the congregation to sing.

First, open the song file containing the songs that you want to categorize.

Second, select the song slides that you want to categorize.

Third, use the 'Set Category' menu in the 'Song Edit' menu on the Worship Service Assistant command bar to set the category of the selected slides to the desired category.
