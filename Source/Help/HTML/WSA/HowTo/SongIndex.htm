How to Create a Song Index

You can use Worship Service Assistant to create an index of the songs in a song file. The index is a separate Microsoft PowerPoint presentation containing the slide number and slide title of the songs in the song file. The songs are grouped by category and appear in the order in which they appear in the song file.

First, use the 'Editor' menu item in the 'Mode' menu on the Worship Service Assistant toolbar to put Worship Service Assistant into Editor mode.

Second, open the song file for which you want to create an index.

Third, use the 'Create Index' menu item in the 'Song Edit' menu on the Worship Service Assistant toolbar to create an index of selected song file. Worship Service Assistant will notify you when it has completed creating the song index. The time needed to create the song index depends on several things, including the speed of the computer and the number of slides.
